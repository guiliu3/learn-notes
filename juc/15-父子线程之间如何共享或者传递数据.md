# 父子线程之间怎么共享/传递数据？
 因为ThreadLocal变量是每一个线程拥有自己的副本，所以不共享
- 参考源码：com.learn.thread.ShareDateParentThreadDemo

- 如果需要父子线程通信，有2种方式
  1. 自己传递
  2. 借助InheritableThreadLocal;


## 自己传递
- 参考源码：com.learn.thread.ShareDataParentThreadDemoForSelf

## InheritableThreadLocal

- InheritableThreadLocal 可以在子线程中继承父线程中的值
```java
if (inheritThreadLocals && parent.inheritableThreadLocals != null)
            this.inheritableThreadLocals =
                ThreadLocal.createInheritedMap(parent.inheritableThreadLocals);

```
