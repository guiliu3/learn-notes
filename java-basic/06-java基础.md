# java基础

## 1. Java语言特性
 - javq程序的运行不受平台限制。
 - java是自动内存管理和垃圾回收机制。
 - java有丰富的社区与框架资源支持


## 2. 如何理解面向对象和面向过程
 - 面向对象：把复杂的任务拆解成多个步骤，每一个步骤之间，抽象出需要的对象，对象具有的属性，共同完成任务。
 - 面向对象的三大特征：
   1. 封装：把事物抽象成一个类，这个类拥有属性和动作，比如汽车类，汽车具有轮子、发动机，拥有动作，加速、刹车灯行为。
   2. 继承：java中的继承是为了复用，但是不能多继承。
   3. 多态: 同一个方法在父类及其各个子类中具有不同含义。

## 3.装箱与拆箱
   把基本类型转换成包装类的过程就是装箱，反之把包装类转换成基本数据类型就是拆箱。
